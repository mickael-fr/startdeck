# Viager Studio - version navigateur

Calculs Python dans un worker Pyodide 314.0.7 (NumPy, pandas, PyYAML, tzdata), PDF ReportLab 5.0.1 et Pillow. Aucune saisie privée envoyée à un serveur ; bibliothèques publiques chargées depuis jsDelivr. ReportLab distribué selon sa licence BSD incluse dans la roue. Pyodide et ses dépendances conservent leurs licences originales. Provenance et fermetures des tables dans python/model/data/mortalite/provenance.yaml. Références fiscales dans le YAML millésimé. Le premier calcul nécessite le téléchargement du moteur ; la connexion Internet est nécessaire pour son chargement.

Exemple entièrement fictif. Import/export et enregistrement local volontaire pour vos propres fiches. Les URLs individuelles Renée Costes sont lues à la demande par le service Viager Studio installé sur le PC (127.0.0.1:8768), qui doit être allumé ; CORS limité à cet import depuis l'origine GitHub du propriétaire. Aucun accès depuis cette origine au profil local, au calcul ou au PDF du serveur. Le navigateur calcule et produit le PDF sur l'appareil. Pas de veille massive ni de synchronisation des études privées. Robots, cache et délai appliqués par le lecteur local ; arrêt sur refus du site, sans contournement. Les conditions d'utilisation des sources continuent de s'appliquer ; aucun accord du site n'est revendiqué. Aucun document de l'utilisateur, profil fiscal, annonce étudiée ou PDF personnel n'est publié. Vente à terme : durée contractuelle des mensualités indépendante du décès, avec scénario défavorable d'indexation et de loyers.
